free spy customized os for 64-bit computers called SpyOS
run on 64-bit computers and virtual machines.
# to run on a usb or hard drive, 
flash to usb and hard drive then open it on a file explorer. add the dpupt save file to root. boot it. select the top boot setting on the boot menu and what for it to boot.
# to run it on a vm, 
download a vm select make new one select the iso give it some mem and lots of ram.
make a shared folder and a external drive put the dpupt save file in the shared folder and boot.
once it gets to the desktop you will mount the shared folder and copy the dpupt save file to the external drive. reboot. you should get the customized desktop.
